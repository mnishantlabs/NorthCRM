Step-by-Step Deployment Instructions

Step 1

Publish Code to GitHub

Run these terminal commands in your local project folder to upload the codebase to GitHub:

git init
git add .
git commit -m "feat: initial release of NorthCRM"
git branch -M main
git remote add origin https://github.com/mnishantlabs/NorthCRM.git
git push -u origin main
Step 2

Create PostgreSQL Database (Supabase)

  1. Sign up at Supabase.com using your GitHub account.
  2. Click New Project, name it NorthCRM, and set a database password.
  3. Navigate to Project Settings → Database → Connection String (URI).
  4. Copy your connection string:
    postgresql://postgres:[YOUR-PASSWORD]@db.xxxxxxxx.supabase.co:5432/postgres
Step 3

Deploy Backend Service (Render)

  1. Sign up at Render.com and click New + → Web Service.
  2. Connect your repository mnishantlabs/NorthCRM.
  3. Configure options:
    • Root Directory: backend
    • Build Command: pip install -r requirements.txt
    • Start Command: uvicorn app.main:app --host 0.0.0.0 --port $PORT
  4. Add Environment Variables:
    DATABASE_URL = [Your Supabase URI from Step 2]
    JWT_SECRET_KEY = northcrm_super_secret_jwt_key_9988
    ENVIRONMENT = production
  5. Click Create Web Service and save your live URL (e.g., https://northcrm-backend.onrender.com).
Step 4

Deploy Frontend Web App (Vercel)

  1. Sign up at Vercel.com and import mnishantlabs/NorthCRM.
  2. Set Root Directory to frontend.
  3. Add Environment Variable:
    VITE_API_URL = https://northcrm-backend.onrender.com/api/v1
  4. Click Deploy. Vercel will build your website and generate your live link (e.g., https://northcrm.vercel.app).
Step 5

Initialize Database & Admin Account

In your Render Dashboard, click your backend service → Shell and run:

alembic upgrade head
python -m app.seed
