# NorthCRM - Complete Guide & Deployment Manual

Welcome to the official documentation for **NorthCRM** (repository: [`mnishantlabs/NorthCRM`](https://github.com/mnishantlabs/NorthCRM)).

NorthCRM is a production-grade, open-source CRM tailored for digital marketing, web development, and service agencies. It helps teams log calls, manage business leads, track deals through sales pipelines, schedule callbacks, and view conversion analytics.

---

## 🚀 Quick Overview

- **Repository**: [github.com/mnishantlabs/NorthCRM](https://github.com/mnishantlabs/NorthCRM)
- **Frontend Stack**: React 19, TypeScript, Vite, Tailwind CSS, TanStack Query, Zustand, Recharts, shadcn/ui
- **Backend Stack**: FastAPI (Python 3.11+), SQLAlchemy 2 (Async), Alembic, Pydantic v2, JWT Auth
- **Database**: PostgreSQL (Supabase / Neon)
- **Deployment**: Vercel (Frontend) + Render / Koyeb (Backend) + Supabase (Database) — **100% Free Resources**

### Step 1: Push Code to GitHub

If you haven't pushed your code to GitHub yet, run the following commands in your project root:

```bash
# Initialize git repository
git init

# Add all files to staging
git add .

# Commit changes
git commit -m "Initial NorthCRM release"

# Set branch name to main
git branch -M main

# Link your GitHub repository
git remote add origin https://github.com/mnishantlabs/NorthCRM.git

# Push code to GitHub
git push -u origin main
```

---

### Step 2: Create a Free PostgreSQL Database (Supabase)

1. Sign up at [Supabase.com](https://supabase.com) using your GitHub account.
2. Click **New Project**, enter project name `NorthCRM Database`, choose a strong database password, and select your region.
3. Once the database is ready, go to **Project Settings → Database**.
4. Scroll to **Connection string**, select **URI**, and copy the connection URL:
   ```text
   postgresql://postgres:[YOUR-PASSWORD]@db.xxxxxxxx.supabase.co:5432/postgres
   ```

---

### Step 3: Deploy the Backend API (Render)

1. Sign up at [Render.com](https://render.com) using your GitHub account.
2. Click **New + → Web Service**.
3. Connect your repository `mnishantlabs/NorthCRM`.
4. Configure the service settings:
   - **Name**: `northcrm-backend`
   - **Root Directory**: `backend`
   - **Environment**: `Python 3`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
5. Under **Environment Variables**, add:
   - `DATABASE_URL`: *(Your Supabase connection string from Step 2)*
   - `JWT_SECRET_KEY`: *(Generates a random 32+ character key, e.g. `northcrm_production_jwt_secret_998877`)*
   - `ENVIRONMENT`: `production`
6. Click **Create Web Service**. Save the backend URL generated by Render (e.g. `https://northcrm-backend.onrender.com`).

---

### Step 4: Deploy the Frontend (Vercel)

1. Sign up at [Vercel.com](https://vercel.com) using your GitHub account.
2. Click **Add New... → Project**.
3. Import `mnishantlabs/NorthCRM`.
4. Edit the **Root Directory** setting to `frontend`.
5. Under **Environment Variables**, add:
   - `VITE_API_URL`: `https://northcrm-backend.onrender.com/api/v1` *(Replace with your Render URL + `/api/v1`)*
6. Click **Deploy**. Vercel will build and assign you a free public domain (e.g. `https://northcrm.vercel.app`).

---

### Step 5: Initialize Tables & Seed Default Admin

1. Open the [Render Dashboard](https://dashboard.render.com).
2. Click your `northcrm-backend` service → Click **Shell** in the sidebar menu.
3. Run the database migration and seeder commands:
   ```bash
   alembic upgrade head
   python -m app.seed
   ```
4. Log into your live Vercel site:
   - **Email**: `admin@northcrm.com`
   - **Password**: `Admin@1234` *(Remember to update your password after logging in!)*

## 🌐 Setting Up GitHub Pages for Documentation

To host this documentation website on GitHub Pages for free:

1. Go to your repository on GitHub: [`https://github.com/mnishantlabs/NorthCRM`](https://github.com/mnishantlabs/NorthCRM).
2. Click **Settings** (top navigation tab).
3. In the left sidebar, click **Pages**.
4. Under **Build and deployment → Source**, choose **Deploy from a branch**.
5. Select branch: `main` and folder: `/docs`.
6. Click **Save**.
7. GitHub Pages will publish your docs at `https://mnishantlabs.github.io/NorthCRM/` within 1-2 minutes.

## 📖 How to Use NorthCRM for Your Own Project

You can clone and reuse NorthCRM for any business or client project:

### Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/mnishantlabs/NorthCRM.git
   cd NorthCRM
   ```

2. **Start Backend**:
   ```bash
   cd backend
   python -m venv .venv
   # Windows: .venv\Scripts\activate | Mac/Linux: source .venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env
   alembic upgrade head
   python -m app.seed
   uvicorn app.main:app --reload --port 8000
   ```

3. **Start Frontend**:
   ```bash
   cd frontend
   pnpm install
   cp .env.example .env
   pnpm dev
   ```
   Open `http://localhost:5173` in your browser.
